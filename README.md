# Explore XY

## GitHub Events × XY

Interactive visualization of GitHub public events using `reflex-dev/xy`

### Objective

Explore GitHub event data at scale and demonstrate XY's capabilities for handling dense and interactive visualizations.

---

### Dataset

GH Archive — hourly archives of public GitHub events.

Events include:

- Pushes
- Pull Requests
- Issues
- Forks
- Releases
- Repository activity

---

### Visualizations
- GitHub activity over time
- Event-type distribution
- Repository activity
- Event density
- Hexbin visualization
- User activity
- Million-event stress test
- XY scaling benchmark

---

### Run
Open [github_events.ipynb](github_events.ipynb) in Google Colab and run the notebook
